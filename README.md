# ShopSphere

A full-stack E-Commerce web application built using React, Spring Boot,
MySQL, JWT Authentication, Razorpay, Paytm, Cloudinary, Railway, and
Vercel.

# Overview

ShopSphere is a modern e-commerce platform that allows users to browse
products, manage carts, place orders, and make secure payments.

# Features: 
 User Registration & Login - JWT Authentication - Role-Based
Authorization - Product Management - Shopping Cart - Order Management -
Online Payments - Admin Dashboard - Cloud Deployment

# Tech Stack

# Frontend: - React.js - Vite - React Router DOM - Axios - Context API

# Backend: - Java 21 - Spring Boot 3 - Spring Security - Spring Data JPA -

# Hibernate - Maven

# Database: - MySQL

# Cloud Services: - Cloudinary

# Customer Features: - Registration & Login - Browse Products - Shopping
